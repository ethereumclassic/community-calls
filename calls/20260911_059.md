### ETC News

- Clients
  - [core-geth v1.12.23 "Argos"](https://github.com/etclabscore/core-geth/releases/tag/v1.12.23) (14 August) backports delayed p2p message decoding from go-ethereum and removes unresponsive bootnodes, with no consensus changes. Is everyone running nodes upgraded?
  - [Fukuii](https://github.com/fukuii-project/fukuii-cli), a new client project, has over 100 commits since mid-August with no tagged release yet. Has anyone on the call tried it?
- ECIPs
  - [ECIPs #580](https://github.com/ethereumclassic/ECIPs/pull/580) proposes changing ECBP-1100 (MESS) from Replaced back to Active, arguing ECBP-1110 only set a disabled default and MESS is still in core-geth. Should its status reflect the code or the recommended default?
  - [ECIP-1111](https://github.com/ethereumclassic/ECIPs/pull/584) and [ECIP-1112](https://github.com/ethereumclassic/ECIPs/pull/585) were merged on 8 September as post-implementation drafts, retitled "Base Fee Market and Redirection" and "Sovereignty Vault". [Olympia's upgrade page](https://olympiadao.org/upgrade) now targets mainnet activation in 2027 with both Mordor and mainnet blocks TBD. Where does Olympia stand? The page also lists an ECIP-1122 among the Olympia parameters, but no ECIP with that number is published, and the ECIPs repo uses 1122 for the ML-DSA draft. What is it?
- Ecosystem
  - ethereumclassic.org added [EIDEX](https://github.com/ethereumclassic/ethereumclassic.github.io/pull/1689), a cross-chain swap aggregator, and [ETCMCv2 DEX](https://github.com/ethereumclassic/ethereumclassic.github.io/pull/1690), a Uniswap v4-style DEX on ETC and Mordor.
  - [ETC rallied about 10% on 9 September](https://ambcrypto.com/ethereum-classic-rallies-as-altcoin-rotation-returns-whats-next-for-etc/) on a jump in spot volume, attributed to altcoin rotation.
- Website
  - [Make Footer Social Links More Neutral](https://github.com/ethereumclassic/ethereumclassic.github.io/pull/1691) (merged 8 September) changes the ethereumclassic.org footer. Previously each social icon linked to a single account or server. Now the icons point to the community channels page, which lists all the options, including both Discord servers, Telegram, the two Twitter Together accounts, and Reddit, so users can choose for themselves.

### Quantum

- [Call 58](https://cc.ethereumclassic.org/calls/58) opened a series on quantum hardening for ETC, with codeaholic presenting the draft [ML-DSA verification precompile ECIP](https://github.com/ethereumclassic/ECIPs/pull/557). The PR has had no new activity since that call. Is codeaholic on the call to continue, and where should the next session pick up?
- ETC only has the execution layer to re-armour, and an address only exposes its public key once it has sent a transaction. Does that make a migration path less urgent for ETC than for Ethereum, or is it worth getting ahead of it now?
- Should quantum work ride the next hard fork, and what would need to be settled first: a precompile, native account support, or an emergency recovery path for already-exposed addresses?
